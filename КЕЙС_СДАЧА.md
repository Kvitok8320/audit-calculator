# Домашнее задание: сайт-калькулятор времени аудиторской проверки

## Паспорт проекта

| Поле | Содержание |
|---|---|
| **Пользователь** | Аудиторская фирма (малый коллектив), принимающая заявки на обязательный аудит у малого и среднего бизнеса |
| **Задача** | Клиент на сайте сам оценивает трудозатраты аудиторов (в часах) по параметрам своей компании и отправляет заявку; аудитор получает её на почту и отвечает со стоимостью |
| **Выбранный состав** | Мини-продукт: одностраничный сайт-калькулятор (адаптивный, ПК + смартфон) с автоматическим расчётом, отправкой заявки на email и печатью результата. Без базы данных — данные хранятся только в письме |
| **Итоговый результат** | Работающий сайт: https://final-seven-lime.vercel.app — расчёт по формуле, письмо с полной анкетой приходит на partner010101@gmail.com |

## Шаг 1. Карточка → план

Идея (карточка): «клиент заполняет анкету о своей компании — сайт считает часы аудита — заявка уходит аудитору на почту».

План минимального инструмента:
1. Анкета: 6 текстовых полей, 11 вопросов с выбором варианта, 12 чекбоксов видов деятельности.
2. Формула расчёта часов (предоставлена аудитором).
3. Кнопка «Рассчитать» → одна строка с результатом + автоматическая отправка письма.
4. Кнопка «Распечатать расчёт».
5. Публикация в интернете (Vercel) + почтовый сервис (Formspree).

## Шаг 2. Минимальный цифровой инструмент

- **Файл**: `index.html` — один самодостаточный файл (HTML + CSS + JS), без сборки и зависимостей.
- **Формула**: Итоговые часы = (ΣЧ + 24) × К × КН × КЛ × КП × КД,
  где ΣЧ — часы по пунктам анкеты (численность персонала с коэффициентом видов начислений, резервы на отпуска, основные средства, транспорт, поставщики, покупатели, незавершённое производство, налоговый учёт, виды деятельности), 24 — фиксированные часы на любую проверку; К = 1,4 за каждое обособленное подразделение; КН — система налогообложения (0,7–1,2); КЛ — число проверяемых лет (1 / 1,8 / 2,4 / 3); КП — организация учёта (1 / 1,1 / 1,2); КД — доступ аудиторов (1 / 1,2 / 3).
- **Отправка**: сервис Formspree (без хранения данных), письмо — на partner010101@gmail.com, адрес клиента в поле «Ответить».
- **Публикация**: Vercel, адрес https://final-seven-lime.vercel.app

## Шаг 3. Исправленная конкретная проблема

**Проблема**: расчёт срабатывал только если во всех вопросах с выбором варианта отмечен первый вариант. При выборе второго или третьего варианта сайт ничего не рассчитывал.

**Причина**: атрибут «обязательно» стоял только у первого варианта каждой группы — при выборе другого варианта проверка считала вопрос незаполненным и блокировала расчёт.

**Правка**: группа признаётся заполненной, если выбран любой её вариант.

**Повторная проверка** (в браузере, автоматическая): вторые варианты во всех группах → «86,9 часов», последние варианты → «277,2 часов», ошибок валидации нет ни в одном случае.

**Непроверенное/ограничение (отделено от фактов)**: лимит бесплатного тарифа Formspree — 50 писем/месяц; поведение при большем потоке заявок не проверялось. Русскоязычный домен и собственный домен сайта не подключались.

## Инструкция для пользователя

1. Откройте сайт: https://final-seven-lime.vercel.app
2. Заполните анкету о компании (поля со звёздочками обязательны).
3. Нажмите «Рассчитать время на работу аудиторов с документами» — под кнопками появится строка «Оценка трудозатрат: N часов», и заявка автоматически уйдёт аудитору на почту.
4. Нужна бумажная копия — нажмите «Распечатать расчёт».
5. Если письма не приходят — проверьте папку «Спам» и отметьте «не спам».

## Ключевые промпты, использованные в работе

1. «Сделай сайт-калькулятор расчёта стоимости аудиторской проверки со следующими полями…» — составлена структура анкеты (все поля, варианты, чекбоксы), задан минималистичный стиль и адаптивность.
2. «Формулы расчёта: [часы и коэффициенты по каждому пункту]… Схема: часы → +24 фиксированных → умножить на коэффициенты, нулевых коэффициентов быть не должно» — реализована функция расчёта.
3. «Калькулятор работает только когда выбраны первые варианты радиокнопок — исправь» — найден и исправлен баг валидации.
4. «Настрой отправку на почту partner010101@gmail.com» — подключён Formspree, затем формат отправки переведён со JSON на стандартную форму.
5. «Задеплой на Vercel» — сайт опубликован.

## Короткий кейс

Аудиторской фирме нужен был способ отбирать заявки на аудит без переписки по каждому вопросу. Раньше параметры компании выяснялись письмами и по телефону; теперь клиент за две минуты заполняет анкету на сайте, сразу видит оценку трудозатрат в часах, а аудитор получает на почту готовую анкету с расчётом и адресом клиента для ответа. Инструмент не требует сопровождения: нет базы данных, сайт бесплатный (Vercel), письма идут через Formspree. Первые реальные заявки получены в день запуска.

## Состав проекта (выбранное и НЕ входящее в состав)

**Входит**: сайт-калькулятор, автоматический расчёт, отправка заявок на email, печать, публикация.
**Не входит и не задумывалось** (не является незавершённым): хранение истории заявок, личный кабинет, онлайн-оплата, мультиязычность, расчёт стоимости в рублях (зависит от ставки часа, определяется аудитором индивидуально).
